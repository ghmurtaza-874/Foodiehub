# 🍔 FoodieHub

**Good Food. Great Mood. Delivered Fresh.**

FoodieHub is a modern, responsive food ordering frontend application that provides users with a smooth and interactive food-ordering experience.

## ✨ Features

- Browse food items and categories
- Search, filter, and sort food products
- Add and remove items from the shopping cart
- Update product quantities and calculate totals
- Add products to favorites
- Apply discount coupons
- Checkout with form validation
- Order confirmation interface
- Responsive design for mobile, tablet, and desktop
- LocalStorage for cart and favorites persistence

## 🛠️ Technologies Used

- React.js
- TypeScript
- Bootstrap 5
- HTML5
- CSS3
- Lucide React Icons
- LocalStorage

## 📌 Project Status

Frontend development project. Backend integration and real payment processing are not included.
